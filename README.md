# 🌐 Personal Developer Portfolio

A responsive, dark-themed personal portfolio website built with HTML5, CSS3, and JavaScript, hosted entirely on GitHub Pages.

🔗 **Live Portfolio:** [https://mubeenali-hub.github.io/Portfolio/](https://mubeenali-hub.github.io/Portfolio/)

---

## 🚀 Overview

This repository hosts the source code for my personal developer portfolio, highlighting my background, projects, technical skills, and educational qualifications in DevOps, Cloud Engineering, and Linux System Administration.

### ✨ Features
- **Responsive GitHub Dark Theme:** Clean UI optimized for desktop and mobile displays.
- **Dynamic Project Status Tracking:** Real-time lifecycle tracking (Completed, In Progress, Upcoming) integrated with GitHub API repository topics.
- **Fast & Dependency-Free:** Pure semantic HTML5, modern CSS variables, and vanilla JavaScript without external heavyweight frameworks.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Modern CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+)
- **API Integration:** GitHub REST API (Topics & Status lifecycle)
- **Deployment:** GitHub Pages
